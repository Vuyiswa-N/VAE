The document describes a GRU-based Variational Autoencoder (VAE) system designed to detect AI-generated text by training only on human-written English and then scoring passages based on reconstruction quality. The encoder uses frozen contextual BERT features with a bidirectional GRU to produce a 32-dimensional latent vector, while the decoder employs static BERT embeddings with the latent vector appended at each step to avoid leakage of future context. The model is evaluated on datasets like HC3 and M4, comparing its AUROC and AUPRC scores against a supervised TF-IDF + SVM baseline. Training involves KL annealing, free bits, and word dropout to mitigate posterior collapse, with experiments run on GPU for efficiency. Results show that AI text often receives lower per-token loss than human text, contrary to the initial hypothesis, with the VAE achieving moderate performance but generally weaker than the SVM, which benefits from seeing full texts. Limitations include reliance on only the first 64 tokens, weak latent space usage, small mixed-domain training data, and sensitivity to template differences in datasets like PeerRead. Overall, the approach highlights the challenges of unsupervised anomaly detection for AI-text identification and the trade-offs between generative modeling and supervised baselines.
